# 数据集后台传输

浏览器上传 XHR 的所有权移至页面外全局内存任务管理，不再随 DatasetsPanel 卸载 abort。上传弹窗的关闭、Escape 和“后台传输”均只关闭弹窗；上传进行时不注册切页的未保存拦截，可继续切换应用页面或项目。仍禁止同项目重复开始上传，新建/登记入口在本项目上传时禁用。返回数据页面订阅已有请求字节与状态，不重新提交。

App 常驻后台传输浮层显示跨项目上传任务，支持收起/展开、当前阶段进度、速度与剩余时间、完成/失败和终止。浮层轮询服务端各项目数据集获取 SFTP 等后端阶段，浏览器接收进度用原 XHR 实际字节；完成记录可关闭清理前端列表。新增按 request_id 终止接口，在尚未显示服务端 dataset_id 时也可取消服务端操作；请求尚未创建时可 abort 本浏览器请求。解压/保存阶段按原规则禁止终止。

仅保证同一网页会话内切页/收起继续，不是 Service Worker 或浏览器关闭后的可靠上传：刷新/关闭浏览器仍可能中断浏览器→后端接收，提供 beforeunload 提醒；后端已收到完整文件后的 SFTP 可独立继续，重新打开可从数据列表查看实际状态。本次不新增分片、持久恢复或断点续传。后端重启仍按原规则中断记录。
