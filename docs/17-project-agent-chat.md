# 项目 Agent 对话

## 使用方式

项目功能导航在“任务”右侧新增“Agent 对话”，路由为 /projects/:id/chat。无需绑定代码仓库即可与 WSL / 本机 Codex 对话；绑定仓库后，项目读写模式同时授权对应代码目录。

页面包括历史对话、新建对话、逐轮用户消息和 Agent 回复、执行状态、日志、停止生成和中断确认。消息支持多行，Ctrl/Command+Enter 发送。输入未发送内容时沿用工作台离开确认。历史记录保存在原项目 code-agent 任务文件中，与“实验 → 代码”的独立开发任务分开显示。

模型留空沿用本机配置。选择权限并勾选授权后可以连续发送；切换对话或改变模型/权限需要重新勾选。默认项目资料与代码读写，另有只读及完整本机权限。每轮最长 30 分钟，同项目与同仓库占用沿用 Agent 执行器管理；停止保留已完成的操作和文件修改，不回滚。

## 连续会话

项目对话启动 codex exec，不使用 ephemeral，记录 thread.started 的 session ID；后续轮次使用 codex exec resume 恢复该项目、该 conversation 的会话，禁止通过客户端直接指定任意 Codex session ID。UI 新建对话生成独立 conversation，不覆盖历史。

CLI 会话由用户本机 Codex 管理，TRASH 的逐轮消息、状态及 session 映射在项目任务记录中。若模型/CLI 未返回 session ID，继续时提示新建对话；服务中断不自动重发用户消息，用户需先确认旧进程已停止。已有独立开发任务继续使用 ephemeral，不复用项目对话。

这是消息驱动的逐轮对话，不是交互终端，也未接入模型 token 级流式显示。页面每两秒拉取状态和已完成的 assistant 消息，日志可手动查看；正在运行时需先停止或等待再发送下一条消息。

## 实际项目操作

当前项目 agent-workspace 下生成项目快照、PROJECT_TOOLS.md 与 project_tool.py。Agent 从环境取得仅本轮有效的工具地址和随机 token，不将 token 写入文件、提示词或返回浏览器；任务结束后失效。工具请求必须匹配当前活动任务和项目，只读权限拒绝 write。

支持的工具操作：

- 读取项目基本信息与文献列表。
- 读取指定文献及带定位信息的解析正文。
- 列出/读取文献卡片、Wiki 和实验结果。
- 新建或修订上述知识对象：调用既有 KnowledgeStore 校验，created_by 为 agent，使用真实 base_version，保留历史并进入待审；不提供自动审核或删除工具。

工具返回记录 ID 和版本，执行日志保存平台记录提示。Agent 不能仅口头宣称已完成修改；默认提示词要求实际调用并检查返回值。实验结果仍需真实数据，不得推测或编造指标。Wiki 的正文可在 Wiki 页查看；文献卡片与实验结果也在原页面读取。

论文草稿可在 agent-workspace/manuscripts 中创建和修改，回复应说明真实路径。该目录目前没有独立网页文件浏览器，需通过后续对话或本地文件管理器读取；草稿不自动注册成 Wiki 或平台附件。若希望在 Wiki 中浏览，应明确要求 Agent 保存为 Wiki。

每轮快照包含最多 200 条文献元数据及各 100 条卡片、Wiki 和结果，标记截取时间与范围；完整最新信息通过工具查询。只读沙箱可能不能访问本机网络，此时仅使用快照与已有文件，须明确说明信息范围。项目读写模式为连接本机工具而开启本次 CLI 网络访问，也允许一般网络访问，界面已说明。此设置仅随单次启动传入，不修改全局 Codex 配置。

权限隔离说明：工具端强制项目归属和读写权限；CLI 的宿主文件读取、MCP 和其他本地 HTTP API 能力仍受所选权限与用户本机配置影响。工具归属校验不等于整个本机进程受到租户隔离，完整本机权限尤其可以访问项目外文件。当前仍是受信任的本地部署模式。
