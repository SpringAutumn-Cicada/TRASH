# 论文项目 Agent 对话界面优化

## 范围与入口

入口仍为左侧“Agent 对话”。参考 CyberTeam 开发员工对话的历史列表、消息排版、输入区、消息目录、复制、过程折叠和滚动交互，在 TRASH 前端独立适配。保留论文研究聊天定位，不增加分支启停、员工设置、测试、合并、发布或终端模块，不修改 CyberTeam 项目。

## 界面变化

- 页头简化为 Agent 标识、研究聊天说明和新建对话；主体使用可收起的历史列表与独立消息区域，输入区固定于聊天主体底部。
- 对话标题使用首条用户消息，列表按最后活动时间排序，显示轮数、日期及活动/异常状态；支持搜索首条与最新一条问题，切换时恢复此页面内暂存的未发送草稿。
- 消息按轮次和时间排版，用户气泡与 Agent 回复区分；提供复制用户消息、复制回复、消息目录定位。纯文本错误、取消和服务中断状态分别展示，中断确认沿用原有接口与人工核对要求。
- 回复展示 Markdown 标题、段落、基础列表、引用、分隔线、安全 HTTP(S) 链接、行内代码、围栏代码块及基础表格；代码块提供复制。全部由 React 文本节点渲染，不执行原始 HTML 或脚本链接；不增加渲染依赖。
- 过程日志默认收起，按需读取，支持刷新及再次收起。运行时显示实际任务状态，不把等待动效伪装成模型实时输出。
- 阅读旧消息时停止自动跟随，出现更新时显示“有新进展 · 回到最新”；消息目录定位只滚动消息容器。新会话/切换会话回到底部。
- 空态提供四个研究场景建议，点击只填入输入框，不发送或启动 Agent。已有草稿时追加建议，不直接覆盖。
- 输入框自动增高，保留 Ctrl/Cmd + Enter，输入法组合期间不触发快捷发送；显示折叠的模型及操作权限选项、权限摘要、显式会话授权与发送/停止入口。没有加入开发测试提示或操作栏。
- 对话列表请求失败后显示连接中断并继续轮询，不冒充模型已连接；发送失败保留草稿，防止重复提交，活动任务在其他会话时提供前往入口并明确停止目标。
- 增加窄屏布局、键盘可访问名称、焦点态和减少动效支持，沿用现有主题变量。

## 行为边界

使用已有 chat/tasks、code-agent/tasks、cancel、acknowledge 接口，不修改后端调度、会话持久化、任务权限与知识校验。当前后端仍轮询任务并在本轮完成后返回最终文本，没有 token 流或中途追加指令接口；界面如实提示等待，不提供虚假的流式消息。

会话草稿仅在当前页面内存中暂存，离开/刷新不持久化，导航或关闭页面沿用未保存提醒，其他会话有草稿时也保持提醒。新建对话不会中断已有任务；完整本机权限不默认启用，切换会话或修改权限/模型后重新确认授权。过程日志仍为原有事件原文，不在本次实现中解析完整工具卡片。

Markdown 为本地基础渲染，不是完整 CommonMark/GFM 引擎：复杂嵌套列表、公式、图片、转义表格和复杂强调格式未完整实现；原始内容可复制，不把不支持格式解释为脚本或外部自动加载资源。没有增加图片附件、语音、多 Agent 或其他未接入的发送能力。
