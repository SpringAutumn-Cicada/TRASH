# 项目文件模块

## 使用入口与范围

项目左侧导航新增“项目文件”，右上角“项目操作 → 本地工作区 / 迁移 → 打开当前目录”也进入此页面。“选择根目录”仍使用原有选择器。

参考 CyberTeam 文件模块的目录树、路径导航、内容预览/编辑、重命名和删除交互，在 TRASH 内独立实现，不修改 CyberTeam 源码或数据。根目录限定当前论文项目的实际工作区，支持已迁移的独立目录和旧项目现有目录。不会因查看文件自动迁移或生成新布局。

页面左侧为懒加载文件树，右侧为目录列表或文件预览，提供面包屑、上一级、刷新、隐藏项开关和全工作区文件名搜索。搜索不解析正文，最多扫描 10000 项、返回 200 个匹配项，截断时提示。单目录最多 5000 项。符号链接显示标识，不跟随链接访问外部内容；迁移后的 raw 别名可通过 literature/originals 查看真实原文。

## 阅读与编辑

- PDF：在页面内使用浏览器原生 PDF 阅读器展示完整原文页面，包含论文中已有的图片。服务提供 application/pdf、字节 Range、文件大小与下载响应；浏览器阅读器提供翻页/缩放，阅读器不可用时可以下载。此能力不表示 Agent 能分析图片，也不新增 OCR。
- PNG/JPEG/GIF/WebP/BMP：直接预览图片。
- Markdown：复用现有安全 Markdown 预览，不执行原始 HTML；支持源码编辑。预览时隐藏 YAML front matter，源码保留完整内容。现有渲染器为基础标题、段落和安全链接，复杂 Markdown 表格、公式、代码块与内嵌图片尚未完整渲染。
- UTF-8 代码、JSON、YAML、日志、CSV、LaTeX 等：按文本显示行号，支持源码编辑。只在线加载至多 2 MiB；过大、二进制或非 UTF-8 文件只提供信息及下载。文本范围按白名单扩展名判断。

保存前比较内容 SHA-256，外部程序已修改则拒绝覆盖，当前编辑保留。切换文件/目录、刷新文件或离开页面时，未保存编辑有放弃确认。普通文件保存使用临时文件后替换；同名上传不会覆盖，失败时移除未完成的临时上传。50 MiB 为单文件上传上限，多文件逐个上传，失败提示成功数量并刷新实际文件列表。

## 管理动作与保护

普通文件支持新建、上传、编辑、重命名、移动、下载和移入回收站；普通文件夹支持新建、重命名、移动和整目录回收。移动目标填写相对工作区的路径，父目录须已存在，同名目标拒绝覆盖。结构性操作检查原文件/目录指纹，防止操作确认期间对象发生变化；目录指纹使用目录清单及文件身份、大小、时间信息，文本保存额外使用内容哈希。

原始文献、解析材料、平台任务/实验内部记录、project.yaml、.git 和 .trash 为托管内容，不允许从文件管理器改名、移动或删除。已登记 artifact 即使放在非标准目录，也不能由普通文件接口修改或移动其父目录。包含平台已绑定代码仓库的目录不允许直接移动或回收，仓库内普通文件仍可编辑。

已配置工作区的文献卡片及 Wiki Markdown 可编辑；保存调用 KnowledgeStore 及既有元数据、证据和 base_version 校验，产生新的草稿版本，保留旧采纳版本。重命名/移动/删除仍拒绝直接改文件，页面提供跳转至卡片/Wiki 模块的入口。未知 ID 的 Markdown 不自动注册为平台知识对象。旧项目尚未配置工作区时，其托管文件维持只读。

项目有活动 Agent、知识任务、上传、复现、分析、实验或 SSH 终端时，拒绝文件写操作。迁移期间文件接口暂停服务；在途文件请求计入迁移的占用检查，上传/保存读取请求体后再次检查迁移占用。目录浏览和通用目录选择能力保持分离，不允许使用文件接口访问工作区外任意绝对路径。

## 回收站

普通文件删除后移动至当前项目 .trash/recycle/<回收ID>/content，并保存原路径及删除时间。回收站对话框支持查看和恢复；同名目标存在时拒绝恢复，不覆盖用户新文件，原父目录已删除时需要先恢复父目录。回收内容随项目整体迁移，不提供永久清空按钮。

回收元数据先写入再移动文件；中断后只有实际存在 content 的条目才显示，恢复成功后旧元数据保留但不再列出。目录内包含符号链接或规模超过指纹上限时拒绝结构性操作，不穿透链接搬动外部数据。

## 接口

均位于 /api/v1/projects/:projectId/files：

| 路径 | 方法 | 用途 |
|---|---|---|
| 空路径 | GET | 当前目录列表，path/hidden |
| search | GET | 文件名搜索，q/hidden |
| preview | GET | 文件信息、可编辑文本及版本 |
| inspect | GET | 结构操作指纹 |
| content | GET | 内联预览或下载，支持 Range |
| save | POST | 文本保存，path/etag/content/version |
| create | POST | 新建文件或文件夹 |
| upload | POST | 原始字节上传，path 查询参数 |
| move | POST | 重命名或移动，path/target/fingerprint |
| delete | POST | 移入回收站，path/fingerprint/confirm |
| recycle | GET | 回收站条目 |
| restore | POST | 按回收ID恢复 |

路径校验拒绝绝对路径、反斜杠、NUL、点及上级跳转，并逐级拒绝符号链接。文本和媒体读取使用不跟随链接的文件描述符。文件原始内容不作为可执行 HTML/SVG 内联渲染；未知类型按下载处理。单次结构操作最多检查 20000 项、深度 128。
