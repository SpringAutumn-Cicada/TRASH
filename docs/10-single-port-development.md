# 开发工作台单端口变更记录

## 范围

本次按用户要求将 ct_dev_test 工作树默认访问端口设为 22223，取消开发时独立的 API 监听和前端代理。业务 API 保留在同端口 /api/v1 下，供界面正常工作。

开发模式由 Node HTTP 服务统一监听，Vite 以 middlewareMode 提供前端并将 HMR WebSocket 绑定到该 HTTP 服务；普通运行模式同端口提供已构建的静态资源。根目录 pnpm dev 不再并行启动两个服务。TRASH_PORT 覆盖统一监听端口。

本次基于 1dec0c2 开发；保留其他既有内容。修改仅提交开发分支，不合并 main、不推送，不关闭已有服务。

## 操作说明

从 ct_dev_test 工作树安装依赖并执行 pnpm dev，打开 http://127.0.0.1:22223。若旧主仓库 API 占用该端口，由用户在旧终端关闭后再启动。端口本身不能识别 Git 分支，以启动目录为准。

现有 pnpm dev 脚本包含启动前构建；本次没有执行该命令。开发分支未检测到 node_modules/.bin，启动前需要用户安装本工作树依赖。锁文件复用已有 Vite 版本，没有升级依赖。
