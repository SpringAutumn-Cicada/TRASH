# AutoDL Python 解释器自动识别

分支：ct_dev_test。基于 c63a581 开发；本次提交记录本功能版本。

选择已连接的目标主机后，部署环境面板自动读取该主机的解释器候选，填入第一个支持 Python 3.8+ 和 importlib.metadata 的路径。提供候选列表及重新识别按钮，仍允许手动填写特殊环境的路径。切换主机或连接状态变化时清空旧路径并重新识别，过期请求的响应不覆盖新主机；检查期间禁止切换，识别期间暂不能检查。

新增复现代码级 GET environment/interpreters?profile_id=...，校验项目、代码及主机归属，仅复用已连接 SSH。远端通过固定 Bash 登录环境读取 PATH、CONDA_PREFIX 及常见 Miniconda/Anaconda/Conda 环境目录，不递归扫描磁盘、数据集，不执行论文代码、不安装依赖。最多尝试 16 个候选；存在 timeout 命令时每个解释器最多 3 秒，整体请求最多 60 秒。输出使用固定前缀与 JSON 格式验证，过滤启动输出，按解释器绝对路径去重；保留解释器符号链接路径，避免把虚拟环境解释器替换为系统 Python。

默认推荐表示主机登录环境中优先发现的可用解释器，不保证满足论文依赖；实际依赖仍由检查 AutoDL 读取并对照。非标准目录可能无法发现，用户可手动补充；发现失败、超时和未找到解释器分别显示提示。登录环境可能与用户已打开终端中临时激活的 Conda 环境不同，因此保留候选切换。
