# 复现代码上传终止

分支 ct_dev_test，基于 15cf04e。开始时工作树干净，核对上传接口、SFTP 传输及前端状态的相关历史，依赖目录存在。

点击确认上传后新增终止上传按钮，适用于本机快照准备、远端目录准备和文件传输阶段。服务端按项目/复现记录/请求 UUID 保存 AbortController；取消接口绕过上传持有的项目锁，同时校验项目内记录和当前请求身份，防止其他上传被误停。返回已请求后显示正在终止，直到原上传请求结束才恢复按钮和关闭能力。

传输阶段取消实际销毁本次 SFTP 通道，拒绝传输 Promise，不关闭共享 SSH 与终端；后续校验、解压及成功记录不会继续。本机快照生成已开始时不强杀 Python 子进程，等待当前快照完成后停止后续上传。远端目录准备中的单个 SFTP 操作同样等返回后在下一阶段边界停止，不把请求已收到冒充已终止。

文件已经传完、进入校验/解压/归档后不再接受终止文件传输，按钮禁用并提示等待结果；服务端独立检查阶段，处理 UI 进度滞后的竞争情况。终止不递归删除远端目录，可能留下不完整 ZIP、已创建的空目录及本机快照；不会登记上传成功，不自动重试、不影响已有上传结果。保留这些残留供用户检查，避免误删其他文件。

实际仅源码阅读、编辑和提交；未运行 lint、类型检查、测试、构建或浏览器验证，未连接 AutoDL、未传输文件。尚未测试，用户验收未执行。待集中验证快照与 fastPut 中止、独立 SFTP 关闭、锁释放、重复取消/结束竞争、校验阶段拒绝以及共享终端不受影响。未合并、未推送、不修改全局配置。
