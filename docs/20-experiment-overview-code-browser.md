## 代码界面

- 左侧目录面板：文件夹优先排序、文件类型图标、文件名筛选、根目录/上一级、刷新、选中态与列表计数。
- 右侧预览面板：完整相对路径提示、语言标记、复制内容、行号、等宽代码、文件大小和行数。
- 目录与代码分别滚动；窄屏上下排列，长代码行在面板内部横向滚动。
- 空目录、未选择文件、加载、读取失败及二进制/超限文件均有独立状态；继续沿用服务端单文件 1 MiB 预览限制与仓库目录边界。
- 首次展示最多 2000 行，超出后可继续显示，避免一次创建过多行节点。语言标记按文件扩展名识别，本轮未引入语法高亮依赖。
- 网页仍只读，不增加编辑、自动提交或远端同步动作。
