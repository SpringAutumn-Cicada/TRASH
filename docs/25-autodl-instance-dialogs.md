AutoDL 信息主界面显示“添加已有实例”和“编辑已有实例”两个按钮，以及当前主机选择、连接信息、指纹和环境诊断。无实例时提示先添加，编辑按钮禁用。原来展开的添加表单移入置顶弹窗，不占主界面空间。

添加弹窗填写可选主机名、SSH 登录指令和实例密码，复用现有创建接口；主机名默认空，不修改远端系统名称。编辑弹窗可选择已有主机，回填名称及 SSH 指令，密码不回显。切换主机会清除当前未保存编辑，界面有说明。支持取消、Escape、焦点约束和关闭后焦点恢复，提交时显示进度，错误留在弹窗中。

新增项目级 PUT ssh-profiles/:id，参数为 name/command/password：

- 保留配置 ID、创建时间和远端工作目录，主机名留空保留原名称。
- 密码留空且连接未改变时保留原会话密码，非空更新服务内存，不落盘。
- 更改密码认证主机的地址/端口/用户名时要求提供对应密码；更改地址或端口会清除已信任指纹。连接变化清除旧凭据及缓存的探测指纹。
- 相同项目已有另一个同连接/认证配置时拒绝重复修改，不覆盖另一主机。
- 有活动实验时阻止配置内容变化，允许同连接仅补充密码，以便恢复连接。
- 旧私钥/SSH Agent 配置留空密码时保持认证方式；填写新密码明确切换为密码认证，界面有提示。

保存成功后关闭弹窗并选择保存的主机，刷新列表、清除旧诊断。已有计划快照仍不可变；配置变化后计划预检查可能提示 SSH_PROFILE_CHANGED，需修订并重新确认。保存实例不自动连接、信任指纹或启动实验。

## 编辑时回填原密码

基于 a60cbd0，按用户明确要求，编辑弹窗不再仅显示空密码占位，而是从本机服务内存读取所选主机的实际原密码，以 type=password 遮罩回填。可直接修改；未修改的回填值不计为未保存编辑。切换主机清空旧值并重新读取，读取中暂禁提交，异步响应按所选主机隔离并在关闭时取消。
