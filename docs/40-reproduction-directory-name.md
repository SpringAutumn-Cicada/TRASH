# 复现代码目录按名称命名

分支 ct_dev_test，基线 2abab66。开始时工作树干净，核对近期提交、复现代码服务文件历史，依赖目录存在；未发现仓库 AGENTS.md。

新导入 ZIP 的本地托管目录改为 repro_<复现代码名称>/code，例如名称“论文A”对应 repro_论文A/code。支持中文、空格和普通标点；路径分隔符、控制字符及不适合作为文件名的字符替换为下划线，去除尾随点和空格，名称部分限制 180 UTF-8 字节，空名称兜底“未命名”。同名目录依次使用 _2、_3 等后缀，排他创建目录，不覆盖已有文件。

已有平台导入的旧目录在下次读取复现列表且无导入/快照/上传操作时按同一规则迁移；修改复现代码名称也同步调整托管目录。迁移使用目录重命名，不重新解压或复制代码；记录路径原子更新，保存失败时尝试回迁原目录。只迁移本项目 reproductions 下、标记 imported 且以 code 为内容目录的托管记录，不重命名旧版绑定的外部目录。未在本轮工具操作中迁移用户实际数据；加载新后端后生效。

记录内部 ID 和 JSON 文件名仍保留稳定标识，避免破坏已建立的计划、快照和运行关联。远端历史路径、快照及其 SHA-256 不因本地目录改名而改写。

开发自验仅 Git 状态、历史与源码阅读，未运行 lint、类型检查、测试、构建或浏览器验证，尚未测试，用户验收未执行。待验收：中文名称、特殊字符、重名、长名称、旧目录迁移、名称修改、迁移失败回退、预览/快照/上传及旧计划关联。未合并、未推送、未修改全局配置、未重启或关闭平台。
