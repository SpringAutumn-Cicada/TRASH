# 修复分屏终端底行遮挡

分支 ct_dev_test，基线 7c96a2d。开始时工作树干净，核对近期提交及终端文件历史，依赖目录存在；仓库内未发现 AGENTS.md。

源码定位：现有 FitAddon 以终端直接父元素的 CSS 高度计算行数，仅扣除 xterm 元素自身内边距。此前直接父元素为带 14px（窄屏 10px）内边距的 border-box 容器，实际可见内容区比测量高度更小，产生底部行被 overflow:hidden 裁剪的问题。

修复：保留外层终端框的高度与留白，内部新增无内边距、无边框的满尺寸挂载节点，FitAddon 和 ResizeObserver 均针对该节点。尺寸计算通过 requestAnimationFrame 合并到布局完成后执行，并在字体就绪后补算，继续将行列数同步给远端 PTY。卸载时取消待执行帧和尺寸同步定时器，避免访问销毁后的终端。适用于新建/关闭分屏、窗口尺寸变化和实验页签重新显示；不重建 SSH 连接，不清空已有 Shell。

实际验证仅 Git 状态、历史及本地 FitAddon 源码阅读，没有运行 lint、类型检查、测试、构建或浏览器验证，也没有 SSH 连接。尚未测试，用户验收未执行。待集中验证：单屏/双屏/三屏的底部提示符，跨 1000px 与 700px 断点，字体加载后尺寸，页签隐藏再显示和关闭分屏后的重排。
