# 实验数据：评估指标与二分类混淆矩阵

在“数据 → 实验数据 → 新建记录 / 查看编辑”填写二分类 TN、FP、FN、TP，默认类别为正常与攻击，可修改名称，正类明确标识。四格输入留空而非默认为零；拒绝缺失、负数、小数、超过安全整数的计数及不安全总数。矩阵热力预览按单元格计数显示深浅，详情可切换计数 / 占总样本百分比。最新与最佳记录卡片显示紧凑矩阵。

默认选择 Precision、Recall、F1 score、FPR，可多选 Accuracy、FNR、Specificity、Balanced Accuracy、MCC、ROC-AUC、PR-AUC。二分类指标由共享纯函数计算，分母为零时不生成分数，界面显示不可计算；AUC 不由四格推算，需手动录入。矩阵计算始终为二分类正类分数，不冒充 macro、micro 或 weighted。前端预览，服务端保存重新计算，避免高级 JSON 中伪造的派生值被直接保存。指标来源、优劣方向为可选字段，旧记录无需迁移。

手动指标可选择常见名称或自定义名称、单位与方向。新分数空值不保存为零；常见百分比在保存时规范成 ratio，MCC 保持 −1～1 无单位；界面将 ratio 转成百分数展示。新增手动常见指标校验范围，旧的无来源自定义指标仍兼容。计数变化会重算所选指标；与手动指标不一致时提醒，二者独立保留，来源与条件分别标识，不覆盖手动结果。移除矩阵时移除其派生结果。

记录补充评估粒度、正类定义、阈值 / 阈值规则和平均方式。最新 / 最好数据按原方法、数据集版本、任务、划分、协议以及新增评价条件、矩阵类别分组；所选指标集合不影响分组。指标比较区分来源与条件，FPR/FNR 默认越小越好，其余常见分数默认越大越好，自定义方向可覆盖。原多次实验聚合接口同步检查评价条件；若同名指标同时存在手动与矩阵值，原聚合接口会明确拒绝歧义，不任取其一。配置和随机种子仍可在最佳单次记录比较中变化，多次聚合仍按原规则检查配置。

使用：填写基本实验信息，添加矩阵并填全计数，勾选计算指标；AUC 或外部报告分数用手动指标添加。保存新版本后在卡片和指标筛选中查看。多分类、预测明细导入、ROC/PR 曲线留待后续。矩阵录入并不证明实验运行有效。
