# 没有数据集哈希时现场建立基线

承接克隆主机接管功能，按用户补充要求，没有数据集 SHA-256 依据时不再仅提示待确认：对新主机已有的数据集目录逐文件执行 sha256sum，保存基线后允许关联接管。原有基线存在时仍进行真正的 SHA-256 比对，内容不一致不会降级为建立新基线来绕过核对。

预览和记录明确区分“SHA 一致”与“新基线”。仅计算新主机当前内容无法证明与旧主机完全一致，因此新基线记录保持 unverified，不覆盖旧主机基线。新基线保存在项目托管目录，以目标主机和来源记录区分；确认接管再次读取并计算，复制到新数据集记录，以供后续迁移比较。

现场生成只读远端，不创建远端目录或修改数据。拒绝符号链接、越界路径和异常输出；最多 10 万文件、16 MiB 哈希输出、单次十分钟，空目录不伪造哈希。计算耗时取决于数据量。代码继续使用已保存源码快照的逐文件 SHA，不改成对自身生成哈希就宣称匹配。
