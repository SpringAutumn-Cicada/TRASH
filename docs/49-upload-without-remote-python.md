复现代码手动上传表单移除 Python 解释器。远端先检查 unzip 命令是否可用，缺失时明确提示，不自动安装。通过 SFTP mkdir 创建唯一快照目录及 code 子目录，使用 SFTP 上传 ZIP；随后通过 SFTP 流式回读，在本机计算 SHA-256 和字节数，匹配后执行 unzip -q -n 解压，最后通过 SFTP 写入快照清单。全部用户路径仍由现有结构化参数转义，不拼接为 Shell 片段；仅固定的 command -v 检查使用 sh -c。不覆盖已有快照目录。
