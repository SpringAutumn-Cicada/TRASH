# 内容顶栏 AutoDL 连接

在项目内容顶栏提供 AutoDL 连接按钮，弹窗集中显示选择主机、添加和编辑实例、连接与取消连接、指纹认证及环境诊断。复用项目现有终端接口和持久 SSH 会话；关闭弹窗不关闭连接。工作区保留终端与分屏操作，实例信息页提供顶栏连接入口。

按钮左侧显示实际连接状态与已连接主机名称。连接弹窗操作后立即刷新，其他入口断开或远端退出由每 5 秒轮询同步；页面重新可见时刷新。读取失败显示状态未知，不将接口失败解释为未连接。切换项目或卸载时取消请求并清理监听与定时器。

## 交付记录

- 操作：前端入口迁移、连接弹窗、状态徽标和跨页面状态通知。
- 版本：本文件随本次功能提交，分支 ct_dev_test。
- 开发自验：仅静态阅读改动和接口调用关系；按本轮约定未运行 lint、类型检查、测试、构建或浏览器验证。
- 用户验收：待确认顶栏状态、弹窗交互、连接复用和跨页面终端恢复。
- 遗留：状态轮询存在最多约 5 秒更新延迟；真实 SSH 交互未验证。
- 生效：默认单端口运行方式需重新执行 pnpm dev 构建前端并重启服务，再刷新页面；本次未主动重启。
