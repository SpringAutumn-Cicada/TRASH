# SSH 交互终端自动设置 UTF-8

分支 ct_dev_test，基线 bba536d。开始时工作树干净，已核对近期及终端相关文件历史、依赖目录及各级 AGENTS.md（未发现适用文件）。

## 操作与行为

在 TerminalService 创建交互终端并注册输出监听后，向该 Shell 写入一次 locale 初始化命令。新连接和分屏共用该流程。通过 locale -a 选择实际安装的 locale，优先 C.utf8/C.UTF-8/C.UTF8，否则选择其他 UTF-8 locale，设置本会话 LANG 和 LC_ALL，随后清理临时变量。

初始化在交互 Shell 启动文件之后执行，避免只依赖 SSH AcceptEnv 或被启动文件覆盖；不改远端全局配置、Shell 配置文件和原始文件名。不使用共享 SSH exec 探测，避免该接口超时销毁共享连接。初始化命令可能显示在终端中，按远端 Shell 的历史策略记录。

没有 locale 命令或未安装 UTF-8 locale 时显示英文提示并保留原设置，不自动安装或生成系统 locale。当前初始化语法适用于 AutoDL 常用 Bash/POSIX Shell；不保证 fish/csh 兼容。

## 验证与遗留

开发自验仅 Git 状态、依赖目录检查与源码差异审阅。按用户要求未运行 lint、类型检查、测试、构建、浏览器验证或真实 SSH 操作。用户验收待执行：重新连接终端及分屏后检查中文 ls 输出，核对 UTF-8 locale 缺失时提示与终端可用性。
