# 文献复现跑实验界面美化

- 分支：ct_dev_test；基于 17f3db7。
- 界面划分为运行方案与主机、数据集与运行顺序、执行配置与结果采集、运行监控四部分，加入编号、说明和顶部主机/数据集/实验记录概览。
- 数据集采用可选择卡片展示名称、版本、路径和验证状态；保留原选择及上移排序行为。
- 每数据集独立参数折叠为高级配置；统一输入框、目录浏览和启动确认区样式。
- 队列状态增加中文显示，列表优先显示数据集名称；阶段进度、日志终端和无实验记录时的空状态采用独立视觉样式。
- 新样式仅作用于跑实验组件，包含窄屏布局；接口、任务执行、轮询和数据存储逻辑保持原有实现。
