# 单窗口终端与共享 SSH 连接

分支 ct_dev_test；实现基线 7ea5fbe。开始时工作树干净，依赖目录存在，核对了近期提交和终端相关历史；未发现适用的 AGENTS.md。

## 操作与版本

修正上一版分屏逐次 SSH 登录的实现：首次连接仍校验主机指纹并认证，新增分屏改用 POST terminals/:id/split，校验来源窗口的项目归属及会话 token，在同一个 ssh2 Client 上打开新的 PTY Shell 通道。不再次读取密码或执行 SSH 握手。各 Shell 工作目录和进程相互独立；连接丢失后不可凭空恢复原 Shell。

所有分屏归入一个黑色终端窗口，使用统一外框及顶部工具栏，保留分屏按钮与 Shift+Alt+D。每项目仍最多三个 Shell。当前窗口只连接一个主机，切换主机须关闭已有终端。关闭单个 Shell 只关闭其通道；最后一个 Shell 关闭时释放共享 SSH 连接。新通道打开失败不会主动关闭其他 Shell 的连接。SSH 连接断开则所有通道结束。沿用原会话输出缓存、逐通道尺寸调整及退出页面清理策略。

终端固定黑色背景、浅色文字与适配的 ANSI 调色板。修正页面通用 textarea 最小高度影响终端内部输入框的问题。

右键复制原实现仅使用 navigator.clipboard.writeText，API 不可用、HTTP 非安全上下文或权限限制时没有兼容处理。现在先在右键用户手势内尝试临时文本域复制，并恢复原焦点；失败再使用浏览器剪贴板 API。仅在浏览器报告成功后提示已复制；都失败时明确告知浏览器限制。没有选区时仍保留原右键菜单，不将终端内容发送到服务器实现剪贴板功能。
