# 复现远端实验与数据集串行队列

文献复现“复现”区域新增“跑实验”，与分析/环境/代码信息/源码互斥展开。选择分析报告、报告运行方案、已连接主机与已部署代码目录，使用该目录 .venv/bin/python。报告命令仅作为可编辑建议，包含多步骤时用 bash -e -c 顺序执行；明确审核后勾选确认再提交，不因打开面板执行实验。可浏览目录，GPU/时限/评价协议/预期指标均可填写。命令参数以 JSON 数组保存，不做隐式 Shell 拼接，只有用户确认的 bash 脚本才作为脚本执行。

数据集来自目标主机的就绪登记，勾选顺序即运行顺序，可上移；每个数据集生成独立计划和运行，支持以数据集 ID 填写单独 command/config。一次实验需要的训练/验证/测试输入可以在同一数据集目录下作为不同子目录参数指定；跨多个独立登记共同输入仍可通过原实验计划指定多个 dataset_ids，本面板多选表示分别运行。命令 {dataset}/{output}/{config} 替换为单项数据集、独立输出和配置文件绝对路径；也提供 TRASH_DATASET_DIR、TRASH_DATASETS_JSON、TRASH_OUTPUT_DIR、TRASH_CONFIG_PATH。代码必须实际读取这些参数/配置，平台不假设自动适配任意项目。

“配置数据目录映射”先通过 SSH 固定只读检查源位置和数据目标，显示源代码相对路径到公共数据路径的预览；实际执行在主机串行锁内创建本次链接，结束时仅移除本次创建且仍指向原目标的链接，不移动公共数据。存在真实目录或其他链接拒绝覆盖，.venv/.git 等保留位置拒绝映射，父目录须已存在且在代码根内。参数/运行配置优先，已有同目标链接可复用不删除。写死绝对路径需人工修订源码，本次不对任意源码进行自动字符串替换。异常强杀可能留下链接，此时需检查，冲突会停止而非覆盖。

队列 JSON 保存在项目 reproduction-queues，单项计划/运行继续使用原数据库存储。服务端逐项确认预检查后提交原执行器，同主机已有活动任务时等待；runner 原主机 flock 继续保证同用户实验串行。启动后核对代码文件 SHA-256（兼容 ZIP 同名外层展开），复用已部署目录与 venv，代码包只作快照依据。每项在 outputs/reproductions/.../<运行ID> 保存日志/配置/产物。数据有已有 SHA 时核对文件或清单，未提供 SHA 只确认存在并保留未验证状态。运行任意论文代码可能按其自身逻辑写代码目录，需核对命令输出参数，不宣称平台能拦住论文脚本所有写入。

队列阶段/计数与当前执行阶段可见，运行/日志分别 2.5秒/2秒同步，日志有 epoch N/M 或 step N/M 时显示原输出步数，不虚构进度；日志最多显示最近 100000 字符。支持取消当前、终止整个队列、失败暂停后重试或跳过、同步远端状态。断线/状态未知暂停不启动下一项；重启暂停全部队列，用户先同步状态再操作，幂等键恢复已提交运行避免重复启动。重试是新运行，不承诺论文训练 checkpoint 自动恢复；旧运行仍保留。队列有暂停任务时先处理或终止，不重复新建。

结果收集复用既有大小/哈希验证：JSON metrics 标准格式，或 CSV name,value,unit,condition 列确定性转换；JSON 可含 confusion_matrix/evaluation，由共享协议计算派生分数。指标名和单位须与预期完全一致，进程成功且有效结果才登记到“数据→实验数据”，保留代码快照、计划、报告、数据集版本、环境和产物。原始文本不由 Agent 自动当成分数。缺失/无效指标暂停队列供处理，日志产物保留；可在原运行接口重新收集。暂无任意 CSV 字段映射 UI、自动改源码适配、模型调参或批量训练断点恢复。
