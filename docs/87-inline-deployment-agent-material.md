# 部署方案材料直接传入 Agent

修复规划 Agent 依赖文件读取工具、因读取被拒绝而无法形成安装计划的问题。后端读取已保存的报告及原分析筛选后的 input.json，通过 stdin 与规划指令一并传给 Agent，明确只使用消息中的材料，不调用文件、Shell 或网络工具。只读沙箱与 never 审批策略保留，不修改全局配置。

input.json 不存在时明确传 null，只使用报告依据；格式损坏或超过 32 MiB 序列化文件上限时在启动 Agent 前报错，不偷偷丢弃材料。仍然只读取原分析托管材料，不额外扫描源码目录，不加入 SSH 凭据。任务目录中的报告和材料副本继续保留供排查。

继续部署只复用结构合法、Python 版本明确、无阻塞且包含安装组的方案。旧记录中因文件读取失败而返回的 blocked 方案重新生成，不再仅因通过结构校验就循环复用。现有安装断点和远端身份核对逻辑不变。
