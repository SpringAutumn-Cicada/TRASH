## 使用流程

1. 在“分析源代码”重新分析，生成 2.3.0 报告。旧报告保留可读；缺少 execution 字段时提示重新分析。
2. 打开“跑实验”，选择报告、运行方案和已连接的主机。代码目录默认沿用该主机最近上传的代码目录，可浏览调整。
3. 为源码识别出的 Trace、Theia 等逐项选择平台数据集。唯一同名记录仅作推荐，首次不自动勾选；可勾选单项或多项，调整顺序，保存绑定。
4. 查看每项自动生成的准备/预处理/训练/评估步骤、评价条件、路径适配和采集规则，无需填写命令 JSON。资源选项提供平台默认 GPU 0、单项最长 7200 秒，支持调整。
5. 检查数据目录与映射，确认后启动队列。同一主机串行执行，每个数据集创建独立运行记录和输出目录；刷新后按后端记录恢复显示。
6. 运行监控按实际阶段和日志显示进度；只有日志提供可靠 epoch/step 总量时显示步数百分比。配置检查、提交和 Agent 失败分析也显示真实阶段状态。
7. 有效结果进入“数据 → 实验数据”，复用已有最新/最佳数据、混淆矩阵及指标展示与评价范围筛选。

原有手动配置保留在折叠的高级模式中，兼容历史报告和特殊实验，不是自动流程的必填项。

## Skill 与报告

每个 run_plan 增加 execution.dataset_runs，逐数据集描述：

- 精确数据集名称、ready/blocked、阻塞项及源码证据。
- 数据子目录、必需文件/目录，以及必要时的临时软链接映射。
- 直接 argv 阶段参数、工作目录、非敏感环境变量与 JSON 配置模板。
- 评价协议与划分条件，JSON/CSV/日志的采集位置、字段/字面量标签和单位转换。
- 仅有明确保存与加载依据时提供 checkpoint 恢复步骤。

所有新增对象沿用文件行号证据校验。ready 表示静态配置完整，不代表实验或适配验证通过。识别不足时列出具体阻塞原因和适配需求，不要求用户猜参数、不编造路径、命令、分数或兼容性。Skill 不执行训练、安装、源码修改或远端操作。

采集器提高指标/结果/工具源码优先级，允许读取 data/datasets 等目录下的 Python/shell 源码，继续排除真实数据、凭据与非源码内容，保持原数量和大小上限。

## 持久化与执行

- 分析报告继续保存在项目 environment-analysis 任务目录，关联 Skill 版本和固定代码 SHA-256。
- 绑定保存在项目 experiment-bindings 目录，按复现代码、报告和主机生成键，保留源码指纹、绑定顺序与更新时间。新的报告不会静默沿用旧指纹的绑定。
- 提交时根据服务端报告实例化各数据集的不可变计划，不接受前端替换报告命令。每次执行保存计划、配置、报告引用、数据集版本及环境；运行和结果复用现有存储。
- 使用已部署代码的 .venv 执行；Python 入口和 PATH 指向 venv。模板替换支持 dataset/output/config/code/python；恢复步骤额外支持 checkpoint。替换按参数进行，不把路径拼入 shell -c/eval 字符串。
- 目录检查和运行时重复核对必需路径及边界；参数/配置传路径优先，软链接仅在需要时创建，冲突停止，结束清理本次创建的链接。公共数据不复制或移动。需要改写公共数据或修改源码才能隔离的方案应在分析阶段标 blocked。
- 每步在源码支持的工作目录启动，超时覆盖整个数据集任务，取消终止当前进程组；后续步骤不会在失败后继续运行。
- 有明确 resume 方案时可“从 checkpoint 继续”，先核对上一次运行目录内文件存在，再创建新运行并保留旧记录。无依据时仅“重跑当前项（从头）”。恢复不是修改旧记录或伪装为原任务未中断。

## 采集与失败分析

JSON 可接收标准指标/二分类混淆矩阵，也支持明确字段路径；CSV 支持标准长表或明确列名的最后一行；日志以有依据的完整字面量标签读取最后一次数值，不执行任意正则。日志仅解析末尾最多 2 MiB；超出范围、缺失或歧义时不能声称完整采集。

原始采集内容保存为 outputs/source-metrics.txt，规则与状态写入 collection.json，归一化输出为 outputs/trash-collected-metrics.json，随产物保存哈希。代码目录中的来源要在本次运行中发生更新，追加日志排除运行前内容，避免复用旧分数。再次采集失败会清除旧归一化文件。进程失败不自动登记有效结果；仅有日志且无可靠指标时明确显示待补充，允许下一数据集继续。

指标进入现有结果协议校验和矩阵计算，保留单位与评价口径；不从 Precision/F1 反推矩阵。静态方案未提供可靠采集方式时只保留日志与产物，不生成假分数。

自动实验失败或采集不完整时启动一次只读 Codex 分析，结合日志、报告、运行配置和采集错误提供原因、依据、后续建议及不确定项。会消耗 Agent token；普通执行进度和指标解析由脚本完成。支持停止与重新分析，不自动改源码或执行修复。CLI 继承平台默认权限配置，未设置沙箱/审批覆盖；提示限定只读任务范围。
