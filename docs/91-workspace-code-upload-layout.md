# AutoDL 工作区目录与运行路径

在「实验 → AutoDL → 工作区设置」选择新实例，填写项目根目录并点击「初始化工作区」。初始化时会保留已存在的普通目录及其文件。成功后按钮显示「已初始化」，后端会直接返回当前状态。已有新版目录的克隆实例可以用「识别已有工作区」。接管成功后按钮显示「已接管」。切换到尚未初始化的新根目录后，可以为新目录初始化。

```text
<AutoDL 项目根目录>/
├── data/<数据集目录>/
├── code/
│   ├── papers/<自研实验目录>/
│   └── reproductions/<复现目录>/
└── outputs/
    ├── papers/<自研实验目录>/run_<id>/
    └── reproductions/<复现目录>/run_<id>/
```

- 自研和复现共用 `data/`。上传使用此目录，远端删除仅适用于其中的独立数据路径。已有的外部数据可按实际路径登记。
- 托管自研仓库沿用本地 `code/papers/` 下的目录名。外部自研仓库以目录名和仓库 ID 命名。复现目录以首次命名和复现记录 ID 命名，修改显示名称后沿用该目录。上传预览和新运行的分组使用同一个目录名。
- 上传使用已固定的代码快照，传输校验、同名目标保护和取消清理沿用现有流程。部署从当前主机的实际成功上传记录读取代码路径，`.venv` 位于该代码目录下。复现上传也可显式选择自定义父目录。
- 配有工作区的主机将新运行按仓库或复现归档，每次使用独立的 `run_<id>/`。历史运行和上传保留当时的主机与路径，日志和产物定位使用运行记录。未设置工作区的运行保留原有备用路径。本地 `experiments/` 仍用于实验方案和归档。
