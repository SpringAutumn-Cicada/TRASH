# 错误出现时保持弹窗位置

分支 ct_dev_test，基于 eba4949。开始时工作树干净，已核对统一弹窗样式及相关提交，依赖目录存在。

原因：上一版通过 :has(错误提示) 动态增加遮罩顶部 padding，并减小弹窗 max-height，触发居中布局重新计算，导致报错时弹窗下移。本次删除这两个条件样式，错误出现/消失不再改变遮罩内边距、弹窗高度上限或居中位置。错误仍作为 fixed 独立层定位；顶部空间不足时提示贴近视口顶部，不挤动弹窗。

仅阅读与修改 CSS，未运行 lint、类型检查、测试、构建或浏览器验证。尚未测试，用户验收未执行。待确认多次错误、嵌套弹窗与窄屏长弹窗位置保持。未合并、未推送、不修改全局配置。

当前单端口模式托管构建产物，需要停止旧进程后运行 pnpm dev，刷新页面生效；本轮没有主动重启。
