# 复现代码移除确认反馈

分支 ct_dev_test，基线 239b96a。开始时工作树干净，核对近期提交与复现页面文件历史，依赖目录存在；未发现仓库 AGENTS.md。

原入口使用 window.confirm，仅其返回 true 才发送 DELETE；浏览器抑制原生确认框时可能表现为点击无反应。本轮未进行浏览器复现，不能断言这是用户现场的唯一原因。

替换为统一 ModalLayer 内的确认弹窗，点击微型删除按钮直接展示复现名称、操作范围、取消与确认移除。提交期间显示忙碌状态，阻止重复提交与关闭；后端错误（包括活动实验阻止）在弹窗内显示。成功后直接更新前端列表、选中项及上传面板，并提示完成，避免删除成功后又因列表刷新请求失败而误报失败。支持 Escape、Tab 焦点循环和关闭后的焦点恢复。

保持既有删除范围：仅移除平台记录，不删除本地源代码、历史快照或远端 AutoDL 文件。本轮未实际删除用户数据。

开发自验仅 Git 状态、提交历史和源码阅读；未运行 lint、类型检查、测试、构建或浏览器验证，尚未测试、用户验收未执行。待验收：按钮打开确认、取消/确认、重复点击、最后一项移除、活动实验与请求失败提示。
