# 数据模块与共用数据集

左侧数据模块位于文献复现之前，使用列表与详情双栏。支持登记远端目录、搜索切换、编辑说明和版本、复制路径、移除登记记录。复用原数据集对象与实验计划数据集 ID，移除记录不删除服务器文件；活动实验引用的记录不可修改或移除。

数据集上传目标固定为所选 AutoDL 工作区的 `data/<数据集目录>/`，支持普通文件、ZIP 保留及解压。首版单文件 200 MiB，ZIP 解压总量上限 4 GiB / 10 万条，拒绝路径穿越、重复路径、符号链接和特殊文件。大型数据集可先在服务器准备后登记目录。进度区分本机接收、压缩包检查、SFTP、解压和保存；终止通过独立接口取消接收或 SFTP 并清理独占创建的数据集目录。解压与最终保存阶段不可终止。已有目录不覆盖、不清理。失败记录保留；后端重启将未完成记录标为已中断，提醒人工核对残留目录。

登记与上传都不宣称数据内容验证成功；原有版本化实验计划保存的数据集快照保持原行为。数据集进度记录随已有项目数据库保存，未引入全局配置。

交付：ct_dev_test，本阶段独立提交。仅静态审阅，未执行 lint、类型检查、测试、构建、浏览器、Python 验证脚本或真实 SSH。用户验收与异常场景待集中验证。需要重新 pnpm dev 并刷新；本次未重启、未上传或删除真实数据。
