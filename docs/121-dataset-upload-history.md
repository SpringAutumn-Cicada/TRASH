# 区分有效数据集与旧上传记录

失败、终止、中断的上传记录归入可折叠“上传历史”，有效登记与上传成功记录保留在主列表。仅前端分组，原记录和状态不覆盖不丢失，成功上传后旧记录自然处于历史，不需要同名覆盖。首次默认选择有效数据集；用户主动选中的历史在刷新期间保持，避免跳转误操作。

列表和详情显示记录编号后8位与版本，历史路径标为“原上传目标（非当前文件归属）”。历史只提供“清除记录”，隐藏远端删除并禁止编辑为假成功状态；弹窗显示具体记录编号，明确同名记录与服务器文件保留。原有清理失败消息保留，并提示核对残留，不能因历史路径相同把后来成功的内容当成旧记录所有。有效数据集保留取消登记/删除数据集功能；服务端原删除接口继续拒绝非ready上传与路径重叠，不降低保护。
