# 克隆主机工作区识别与接管

工作区设置增加“识别已有工作区 / 确认接管”，可选择来源主机，默认带入原根目录，新主机路径不同时可修改。使用目标主机已连接的 SSH，只读取 datasets、reproductions、experiments、outputs 等必要目录。识别和接管均不创建、移动或修改远端文件；必要目录缺失时显示具体项，不静默初始化。仅绑定目录时可不选择来源。

按用户补充要求，内容核对使用 SHA-256，而非目录名、快照 ID 或远端快照标识。复现和实验代码使用本机已保存的源码快照逐文件哈希，新主机运行 sha256sum，兼容原 ZIP 外层展开；不整包回读、不依赖远端 Python、不扫描 .venv。批量核对已记录文件，不宣称额外文件或依赖环境已验证。符号链接越界和非普通文件不接受。

新数据集上传在本机生成文件 SHA-256 基线：普通文件在接收过程中计算，ZIP 在安全检查时计算成员哈希，基线保存在项目托管 dataset-hashes 目录，不进入全局配置。克隆接管时逐文件比对；历史数据集无文件基线时使用已有 sha256 与 checksum_manifest 或文件路径。仅清单哈希相同不代表数据文件完整性已验证；无哈希、不一致或无法读取的项标为待确认/跳过，不自动关联。旧版本上传不会凭空补出可信基线。

确认接管重新识别，给目标主机新增匹配的数据集和代码关联，保留旧主机记录和历史任务，不重写旧运行状态。数据集记录不冒充完整数据验证成功。重复接管去重；本地保存异常时可能存在部分已关联记录，可重试补齐，不删除旧记录。工作区本地配置记载接管时间与来源，安装计划在同报告、同解释器、路径映射一致且原计划有效时可复用；远端 runner 仍执行代码和 venv 断点身份核对，不自动部署，不宣称克隆 venv 已可运行。
