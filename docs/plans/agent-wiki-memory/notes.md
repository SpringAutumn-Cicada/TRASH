## 实现

- 项目skill及cards/wiki参考规则：卡片保留人类阅读结构；Wiki为Agent研究记忆。先开放阅读文献机制、假设、异常、分歧和边界，再比较去重，最后关联项目。项目题目不是主题边界，允许暂无直接项目关联。
- 单篇分析仍一次发布双卡片与一个稳定ID的短线索笔记，线索笔记软目标300–600字，不再复述详细卡片；无线索明确暂未发现。关键卡片可保留1–3行主题线索。
- 全项目综合不再固定生成背景/方法/数据集等四页，新增discovery阶段。先生成Markdown发现清单，再按实际证据条目动态创建知识主题或待验证假设，最后生成Agent导航总览。用户手工指定的主题保留直接综合入口。
- 新增wiki-topics.ts：识别清单的知识主题/候选线索/研究假设二级标题，规范化精确重复名，匹配实际提供材料ID；证据不足不创建正式页。单篇知识主题要求单篇价值理由。没有主题需显式“未发现可整理主题”；格式无效报错，不报告成功发现。
- 每轮最多自动发布8个正式主题/假设，其余仍保留在发现清单。主题发现获得最多100项已有主题的轻量标题索引，优先复用同义主题标题；附总数，超出时不声称覆盖完整历史去重。标题完全一致沿用现有文件和版本历史，语义合并仍由Agent判断。
- Wiki新增discovery/hypothesis层级并同步协议、筛选、标签和任务进度。研究假设标题明确“待验证”，默认不自动审核。
- Wiki结构：何时读取、核心认识及就近证据、分歧与条件、未知/验证方式、项目关联、深入阅读。主题软目标800–1500字，总览500–1000字；不硬截断证据。
- 索引摘要优先使用何时读取/适用问题段；没有则保留原来的开头摘取。索引签名升级以刷新现有v2索引摘要，不改正文。
- 对话工具说明同步新层级和开放主题规则，仍按需读取、直接写Markdown，不返回正文JSON。
- 提示词版本5及任务元数据同步。全项目自动复用要求新版本任务，避免旧模板被当成本轮新规则结果复用；已有文件不批量改写或删除。

## 限制/验收

语义同义去重、主题质量、软字数和实质证据支持程度由Agent执行，平台只校验格式/实际材料ID及预算，并不能替代研究者核对。跨轮同义标题仍可能需要人工合并；超过100项的历史主题不做全库语义查重。
正式主题选择每轮最多8项，所有发现保留清单。超出输入预算仍明确失败，不默默截断。已有长Wiki保留，下次明确生成/更新才应用新规则。
用户可先分析单篇查看简短线索，再执行“综合已有卡片”，核对发现清单、主题/假设、证据和总览；本轮未替用户发起此流程。
