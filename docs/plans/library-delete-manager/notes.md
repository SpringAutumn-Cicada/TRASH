# 文献统一删除管理
日期：2026-11-14；分支：paper_analyze；版本：本记录所在提交。

## 范围
- 核对中断后的工作区为干净状态，无残留执行中的修改，不重复既有写入。
- 全文库在“导入文献”右侧、摘要库在“录入摘要”右侧增加共用“删除文献”入口。
- 弹窗提供标题/作者/DOI搜索、逐项勾选、全选当前筛选结果、已选数量与清空选择；筛选前选择保留，并明确提示。
- 删除前展示全部所选文献供二次核对；顺序调用既有删除接口，逐项保留失败原因，成功条目即时从当前库移除，失败条目保留选择。
- 删除期间禁用关闭、选择和重复提交，支持正常状态下Esc与键盘焦点限制。
- 移除全文列表行内删除按钮及旧的单条删除弹窗。
- 复用现有后端保护：有活动任务或知识引用的来源不能删除，原始文件保留，不删除额外数据或知识文件。
- 成功删除后清理对应行、阅读目标、检索结果和Wiki反馈，避免悬空显示。
