# 章节阅读与新版Wiki交付记录

范围：章节/版面识别、结构与预算分块、图文阅读及恢复、最新单篇Wiki生成、出处锚点与旧入口兼容、基本阅读和进度展示。不实现显式范围渐进读取、新检索排序、向量检索或跨论文大背景。不自动批量重生成旧论文。

阶段一：PDF.js提取逐行区域、字号、字体线索、页尺寸和书签候选；双栏启发式阅读顺序；规划器识别标题层级并记录置信度，完整章优先，长章组合连续子节，必要时段落或无文字页图像兜底；保留引导段、排除页眉页脚的记录及覆盖检查。无OCR能力时明确标记，复杂版面仍需原图核对。

验证：尚未运行测试、lint、额外类型检查、构建、浏览器或真实模型生成；功能验收待后续记录。所有结构检查仅证明范围及格式，不证明原文已正确理解。

阶段二：替换固定四页循环，按章节计划提供目标文本与完整页图像；保留必要的前序术语笔记，拆分章节先整合，再形成整篇认识和页计划。检查点绑定原文、完整计划、当前块及前序笔记哈希；旧四页笔记不冒充新结构完成状态。原始章节、低置信度、目标区域、阅读阶段、降级与覆盖记录均保留在任务目录。
