# 文献行布局、内容弹窗与分析续接

分支：paper_analyze。基线：92d065b。工作区开始时干净，依赖已安装。

## 范围与完成情况
- 移除发表时间列与“已索引”，年月按 YYYYMM（仅年份时 YYYY）置于作者前，使用分隔点及 11px 间距。
- 保留 PDF 图标与两行标题；标题右侧以 2×2 入口显示基础信息、关键卡片、详细卡片、Wiki，窄屏四入口下移。
- 移除省略号及重复分析菜单，保留有确认的微型删除；状态紧邻分析按钮。
- 分析按钮使用四字状态：开始分析、正在提交、查看进度、继续分析、重试分析、重新分析。
- 内容按需读取并弹窗展示，支持四类切换、Markdown 编辑、版本历史与关联文档；保存使用文件 hash 防止覆盖并发编辑；基础卡保存沿用书目信息保护规则。
- 单篇失败/中断/取消可重试，挂接原任务 attempt_of。阅读续接跨多次失败沿任务链查找，以 PDF hash、skill hash、补充阅读要求和阅读版本筛选笔记；无效批次重新阅读。新批次保存笔记 hash。
- 兼容旧 prompt_version=6 的已完成批次：旧清单没有笔记 hash，沿用其完成状态、同原文 hash、同 skill/要求、普通文件和大小校验；复用后在新任务记录 hash。不是恢复模型会话，也不把半成品当作已发布。
- 最终综合失败时复用全文笔记后重新综合，不复用未校验的最终 Markdown；发布沿用已有原子文件提交与版本冲突保护，不覆盖人工新修改。
- 没有主动触发模型任务、删除文献或修改现存研究内容。

## 验证约定
只执行必要构建、重启前活动任务检查、启动后只读接口检查及 Git 静态差异检查。不执行测试、独立类型检查、lint、浏览器或真实模型验收。
