# 失败任务删除入口

失败任务详情增加红色删除按钮和二次确认，仅移除任务列表记录。DELETE knowledge-tasks/:id 要求 confirm=true 并在 UPDATE 条件中校验 status=failed，其他状态拒绝删除。使用 deleted_at 逻辑删除以保留工作流引用、续接祖先、日志、草稿与已发布内容；列表排除已删除记录。未实际删除用户任务。
