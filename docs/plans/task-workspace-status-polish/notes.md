# 任务工作台视觉与当前状态

范围：仅任务工作台前端。列表、日志、详情及当前任务页面滚动条使用细窄圆角样式，去掉箭头按钮；加强选中列表边线、标题字重、辅助文字与状态标签对比。运行蓝、失败红、中断琥珀、完成绿。失败与中断独立筛选及计数，中断详情使用独立提示。

状态：沿 attempt_of 查找后续尝试，活动优先、最新其次；已有后续尝试的失败/中断/取消记录只在“历史”中展示，当前列表和失败/中断计数不再重复计入。默认选中历史尝试时自动定位后续任务；历史入口仍保留原状态与日志，不篡改后台状态。生成、校验、补救、发布进展加入执行进展日志筛选，避免仅显示原始输出。
