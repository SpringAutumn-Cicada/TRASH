# 文献删除的阻塞范围

原因：DELETE sources 接口以整个项目的分析/代码任务状态拦截；存储层又因项目内任意排队或运行中的知识任务拒绝删除，导致无关任务也阻塞操作。

调整：去除删除文献接口的项目级任务锁；在存储事务内按 source ID 检查活动知识任务持有的输入和快照引用。目标文献在排队中或运行中的任务资料里仍拒绝删除，使用独立 SOURCE_HAS_ACTIVE_TASKS 错误，不要求断开 SSH。保留历史引用与合并引用检查，补充当前 Markdown 卡片/Wiki 对文献及文献卡片的引用保护。工作区迁移限制保留。未实际删除用户文献或停止任务。

开发自验：审阅差异、git diff --check；按分支持久授权执行构建。未运行测试、lint、额外类型检查、浏览器或真实删除验证。用户验收待执行。

交付版本：本次 fix 提交（见本文件 Git 历史）。pnpm build 成功，有前端大 chunk 提示；现有服务健康接口返回 200。当前 1 个 running、2 个 queued 知识任务，未重启，新后端限制需任务结束后重启生效。本次没有执行真实删除验收。
