# 项目配置与名称编辑

项目菜单入口和弹窗统一为“项目配置”。基本信息区可编辑项目名称并单独保存，PATCH /projects/:id 严格校验 trim 后1–120字符，仅更新数据库标题和更新时间；返回新项目数据，导航、顶部标题、项目列表使用同一状态立即同步。项目ID、文件夹及材料路径不变。无需结束无关任务即可修改显示名称。

弹窗重构：固定标题与底栏，主体独立细滚动条；基本信息、存储位置、迁移记录分组，迁移表单默认折叠。目录使用紧凑等宽文本块，统一间距、边框与字号；保留外部引用、进度、历史备份及清理确认。迁移操作独立按钮，避免保存名称触发迁移；保留未保存更改提示和焦点约束。

开发自验：审阅差异、git diff --check；按分支持久授权 pnpm build 成功，仅Vite大chunk提示。未运行测试、lint、额外类型检查、浏览器或真实改名/迁移操作。当前1个运行中、9个排队任务，未重启以免中断；前端热更新，新增改名后端接口需队列结束后重启。用户验收待完成：名称保存及导航同步、长路径布局、移动端显示、迁移与备份既有操作。
