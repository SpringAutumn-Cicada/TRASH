# 单篇论文分层知识交付记录

范围：单篇全文论文的 index.md 与问题、方法、贡献、证据、局限、综合认识知识页；不改变摘要生成和跨论文主题规则。

阶段一：新增嵌套知识路径和来源隔离ID；生成任务支持必需职责与按需机制/证据子页；整组原子发布、版本冲突、大小与数量限制；索引可达性及本篇断链检查；旧卡片保留稳定入口和版本历史。完整论文分析会读取原文，Wiki重组仅使用本篇已有材料。

旧资料策略：不在服务启动时批量调用模型或机械拆解研究事实。既有正文仍可阅读；逐篇点击“分析Wiki”重组为新知识页，保留原版本和人工内容；完整重分析后旧key/detail/memory变为兼容投影/入口。题录basic保留接口数据。旧知识不会被当作本轮重新核验的原文证据。

开发验证：待必要构建与部署后追加。尚未运行测试、lint、额外类型检查、浏览器验证或实际模型生成；用户验收待执行。

阶段二：目录按论文索引、独立知识页、方法与机制、实验与证据显示层次；旧卡片单列兼容入口，原Wiki按钮优先打开论文index；知识图谱区分索引与知识页，按真实Markdown链接展示关联。维护入口的论文生成也接入新协议。首次必要构建成功；Vite提示既有大包体积警告，未作为失败处理。
