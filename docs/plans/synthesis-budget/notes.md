# 综合输入预算与默认模式

Wiki 综合入队时，已有卡片会被重新读取；此前仅按分组预算控制，但单个 Wiki 任务仍可能累计超过 60000 字符，直接返回 KNOWLEDGE_INPUT_TOO_LARGE。现在仅对 wiki-page 综合任务按文档数量分配约56000字符预算，保留标题、frontmatter、开头结构和证据附近内容，超出部分写明已按综合预算压缩；全文 Markdown 和已发布卡片文件不改写。单篇全文卡片任务仍在超过输入上限时明确失败，避免静默截断原文。

批量操作默认改为“综合已有卡片”，不再默认启动补齐和全文重读。补齐更新并综合仍可从菜单显式选择。综合阶段只使用已发布卡片和 Wiki 资料；失败后已有卡片保留。

开发自验：代码审阅、git diff --check；未运行测试、lint、额外类型检查、构建、浏览器或真实模型。用户验收待完成：默认选项、超限综合可继续、内容压缩提示和原始卡片保持不变。
