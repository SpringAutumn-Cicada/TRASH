# 数据集上传后自动核对文件一致性

- 分支：ct_dev_test；基于 4e5d0fe 开发。
- 上传流程：浏览器分片接收、远端传输及解压后，使用上传时保存的原文件/ZIP 成员 SHA-256 对照远端文件，完成后保存校验结果与时间。
- 远端仅运行 sh、readlink、sha256sum、cut，无须调用 Agent，不消耗分析 token。按每批最多 32 个文件更新真实计数进度；单个大文件计算期间不虚构字节进度。
- 数据集详情新增“校验文件／重新校验”；要求已连接对应主机，任务在后端执行，刷新页面通过现有轮询恢复进度。
- 校验期间禁止修改或删除该记录。校验失败保留远端文件，可排查后重新校验；后端重启后显示中断，不保留虚假的正在校验状态。
- 没有可信参考 SHA-256 时维持未验证。仅提供 checksum_manifest 的哈希时，核对范围只包含该清单文件，不代表核对清单中的数据。
- 一致性仅覆盖参考清单内文件，不检测额外文件，不保证标签、格式或实验适用性。校验会完整读取远端文件，产生远端磁盘 I/O。

## 验证和验收

开发仅进行源码阅读和改动审阅；按本轮用户规则未执行 lint、类型检查、测试、构建、浏览器或真实远端验证。用户验收尚未进行。

待验收：普通文件和 ZIP 上传自动验证、缺失/修改文件报告失败、无参考哈希维持未验证、手动校验刷新恢复、校验期间编辑删除保护，以及远端工具缺失和断线提示。

生效需要重启 pnpm dev 并刷新页面；请等待当前上传任务结束后再重启，避免中断任务。
