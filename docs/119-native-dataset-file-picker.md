# 数据集使用系统原生文件选择框

“选择本机文件”现在优先打开系统原生选择框，移除简易 WSL 网页目录列表。WSL 通过固定 PowerShell STA 脚本调用 Windows OpenFileDialog，路径经 UTF-8 Base64 回传避免中文编码损坏，再由 wslpath -u 转为后端可访问路径。Windows 后端直接使用同一选择器；其他 Linux 后端尝试 zenity，不可用时提供完整路径输入。手动路径支持 Windows 盘符/UNC（WSL 转换）和 Linux 绝对路径，检查存在、普通文件、非空和 5 GiB 上限。

前端等待系统选择时展示状态，取消系统选择不报上传失败，可重新选择或手动粘贴。最多等待五分钟，服务端防止重复打开选择框。网页弹层在系统选择期间不关闭，避免产生孤立选择进程；系统选择框可由用户取消。原生框可能在 Windows 任务栏后面，需要切回查看。实际路径、磁盘读取、校验和 SFTP 仍由 WSL 后端完成，不通过浏览器传文件、不默认复制到 WSL。Windows 挂载盘的跨文件系统读取开销仍可能存在。
