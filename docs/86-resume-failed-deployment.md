# 在原记录继续部署

失败及取消的部署卡片增加“继续部署”按钮，使用该记录的报告、主机、目录和解释器，不受当前表单选择影响。请求携带 resume_id，服务端校验所有参数与记录一致，仅允许失败或取消的任务恢复；保留记录 ID 与创建时间，在原卡片展示新进度。未连接原主机、其他部署进行中时不可继续。代码时效、上传快照及 SSH 校验仍适用。

每次继续使用独立远端任务目录，避免旧 cancel 标记或已存在目录影响执行；源码目录中的 venv 断点仍按代码、有效安装计划和解释器身份复用。旧任务日志文件保留在远端，卡片显示本次尝试的日志。

截图中的 python_version 报错来自 Agent 安装计划格式校验，发生在启动远端安装之前。原实现只判断 plan.json 存在便复用，会反复加载无效方案。现在先验证方案结构，无效方案重新交给 Agent 生成，提示要求明确数字版本，不确定时返回 null 并阻止安装；不将版本范围强行转成猜测版本。格式失败显示可读原因，不直接呈现 Zod 错误数组。
