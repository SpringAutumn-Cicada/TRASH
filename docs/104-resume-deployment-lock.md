# 继续部署项目锁处理

同一项目、同一代码、同一报告的并发时效检查共享正在执行的快照扫描 Promise，只在扫描结束后继续，避免页面检查与点击继续部署重复获取排他锁。共享仅覆盖进行中的请求，不缓存时效结果，不跳过代码指纹核对；扫描失败或成功均移除共享项并按原规则释放锁。

部署入口在扫描前检查本项目本机部署/分析/修复是否仍执行，返回明确 DEPLOYMENT_BUSY，不将其误报成普通快照占用。部署准备取得项目锁后统一捕获同步异常并释放；后台任务成功启动后仍由任务结束时释放，避免工作区或历史记录读取异常留下占用。busyProject 同时包含正在执行的本机任务，覆盖失败分析阶段。

不强行解除真实上传、其他报告扫描或其他检查持有的锁，不终止其进程，不绕过代码一致性检查。已有进程中的异常遗留锁需要重启服务清除；本次未主动重启。新逻辑需要重启后端并刷新页面。
