# 本地目录路径复制兼容处理

分支 ct_dev_test，基线 11eebf1。开始时工作树干净，核对近期提交和复现代码文件历史，依赖目录存在；未发现仓库 AGENTS.md。

用户提供的路径长度通常不是复制失败原因。源码中复制目录仅调用 navigator.clipboard.writeText，没有像终端复制那样提供兼容路径；HTTP 非安全上下文、API 不可用或浏览器权限限制均可能导致失败，未实际检查用户浏览器，不能认定具体权限原因。

新增共享 copyText：在点击手势内先尝试临时只读文本域和 execCommand('copy')，不支持时使用现代剪贴板 API。临时节点自动删除，恢复原焦点与 DOM 选区；弹窗内使用时节点挂载到弹窗，避免背景 inert 阻止聚焦。复制目录及代码浏览器的文件内容复制共用此处理。只在浏览器报告成功后提示成功；目录复制失败时给出手动选中路径并按 Ctrl+C 的说明，成功会清除旧失败提示。没有缩短或改动原路径。

开发自验仅 Git 状态、历史和源码阅读。未运行 lint、类型检查、测试、构建或浏览器验证，尚未测试，用户验收未执行。待验收：localhost/HTTPS/HTTP 局域网访问、所述长路径、复制权限拒绝、剪贴板实际内容、焦点及选区恢复。浏览器完全禁止写入时仍需手动复制。

未修改全局配置，未合并、未推送、未重启或关闭平台。
