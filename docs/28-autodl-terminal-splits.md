# AutoDL 终端外观与分屏

分支：ct_dev_test；实现基线：ccb4b55。开始时工作树干净，依赖目录存在；只读核对近期提交及相关终端历史，仓库内未发现 AGENTS.md。

终端使用代码浏览器相同的主题色、圆角、边框与工具栏，增加窗口编号、连接信息和焦点边框。终端配色跟随页面主题属性变化。宽屏并排排列，1000px 以下纵向排列。

每个窗口右上角提供新建分屏、恢复显示、关闭按钮。终端输入获得焦点时，Shift+Alt+D 新建同主机的独立 SSH Shell；按住快捷键不重复创建。每项目本页面最多三个窗口，建立连接期间阻止重复请求。沿用后端每项目三个终端和主机指纹、会话凭据校验，不额外安装远端环境。各窗口独立输入输出与尺寸调整，关闭单个窗口保留其余会话；已结束窗口保留输出，关闭后释放页面位置。

选中文字后右键复制到系统剪贴板，并显示反馈；没有选区时保留默认右键菜单。剪贴板被浏览器权限或非安全上下文限制时显示失败说明，不声称复制成功。切换实验页签保持所有终端，离开实验页面仍清理会话。关闭 Shell 可能中断前台任务，长任务使用 tmux 或实验 Runner。

本记录更新 docs/26 中“前端本页维护一个终端”和“切换其他主机前需要断开”的旧行为描述；现在可在三窗口限制内连接多个主机。
