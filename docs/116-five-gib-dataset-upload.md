# 数据集上传上限提高至 5 GiB

数据模块上传支持单文件最大 5 × 1024³ 字节（5 GiB，约 5.37 GB，包含 5GB 文件）。前端选择检查、后端 Content-Length 提前检查、流式接收累计字节检查保持一致，超过返回 413。ZIP 解压总量从 4 GiB 提高到 5 GiB，保留 100000 条目、安全路径、禁止符号链接和加密等规则，复现代码 ZIP 的 200 MiB 限制不变。

继续用流式落盘和分块 SHA-256，不将整个文件读入内存。HTTP 服务接收请求总期限设置为两小时（作用于该服务的 HTTP 请求接收，原请求体大小限制仍有效），避免默认五分钟接收期限中断大文件；ZIP 本地校验和远端解压期限分别提高至三十分钟，解压阶段仍不支持终止。上传和解压需要本地临时磁盘、远端目录有足够空间；超慢连接超过期限仍会失败，不承诺分片或断点续传。完成、取消或失败按原规则清理临时文件和本次拥有的远端目录。
