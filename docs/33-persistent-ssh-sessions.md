# SSH 连接跨页面保持

分支 ct_dev_test，基线 38a9842。开始时 Git 工作树干净，核对近期提交、终端文件历史及相关页面挂载逻辑，依赖目录存在；未发现仓库 AGENTS.md。

原问题：项目功能切换会卸载实验页，终端组件的卸载回调主动 DELETE 会话；此外服务端会在无输出订阅 30/60 秒后关闭 SSH。两者都导致点击其他界面后需要重新登录。

本次移除终端卸载时的 DELETE 和无订阅超时关闭逻辑。会话归本机服务持有，不因页面切换、浏览器刷新或关闭页面而主动断开。新增 GET 项目 terminals 接口返回该项目当前活动 Shell 的描述符及运行期 token，响应禁止缓存；实验页重新进入时自动获取并附着原会话，无需重新认证或创建 Shell。该接口遵循现有受信任本地部署和项目检查，token 不保存至浏览器持久存储或日志。每通道保留最近约 1 MiB 输出，超出缓存的旧内容仍会截断，不承诺恢复无限历史。

工作区顶栏增加“断开连接”按钮，关闭本页所有 Shell；各 Shell 关闭按钮继续仅关闭对应通道。最后一个通道关闭才释放共享 SSH 连接。删除项目或修改主机时依旧受活动会话保护，需要先断开。不自动重连已经丢失的 SSH：网络断开、实例关闭、远端 Shell 自行退出或 TRASH 服务重启仍可能结束连接，界面如实显示，不将新 Shell 冒充旧会话。需要长任务跨本机服务重启持续运行时仍应使用 tmux 或实验 Runner。

实际开发自验为 Git 状态、历史及源码阅读，未运行 lint、类型检查、测试、构建、浏览器验证或真实 SSH 连接，尚未测试；用户验收未执行。待集中验证：切换项目功能、返回项目列表、切换项目后返回、刷新浏览器、无页面订阅超过一分钟后恢复、分屏关闭及总断开、远端退出和网络中断、原输出回放和项目隔离。新后端逻辑需用户重启 TRASH 生效，本轮未重启或关闭平台。
