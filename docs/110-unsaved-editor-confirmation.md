# 实验记录关闭与切页确认修复

实验记录编辑后的关闭、切换记录及应用内导航此前使用 window.confirm；在嵌入式环境中原生确认可能被宿主拦截，使操作直接返回且未保存标记仍阻止导航。改为统一的应用内确认弹窗，复用 ModalLayer，显示“继续编辑”和“放弃修改并继续”，支持 Escape、焦点初始化与 Tab 循环。

关闭实验记录时无改动直接关闭，有改动确认后关闭并同步注销未保存标记。新建或编辑另一条记录也使用同样确认，取消保持输入。切换页面或项目时保留待执行跳转，确认后完成原跳转，不要求用户重复点击；取消停留。浏览器前后退沿用原回退恢复逻辑，确认后再前往目标历史位置。新建项目等原 canLeave 调用改为确认后回调，避免异步弹窗吞掉操作。刷新/关闭浏览器仍使用 beforeunload 提醒，这是浏览器原生离站保护，与应用内确认分开。

交付分支 ct_dev_test；开始工作树干净、依赖目录存在，已读取相关历史与表单、导航、ModalLayer，未发现仓库 AGENTS.md。开发自验仅静态审阅，未执行 lint、类型检查、测试、构建或浏览器。实际效果待用户验收，重点覆盖修改后关闭确认/取消、原生 JSON 编辑、切页/切项目、前后退及确认后的焦点恢复。仅前端修改；当前 pnpm dev 静态页面模式需要重新运行并刷新，独立 Vite 模式无需重启后端。本次未主动重启、推送、合并或修改全局配置。
