分支 ct_dev_test，基线 13c1006。开始时工作树干净，已核对近期提交及现有终端、SFTP 实现，依赖目录存在；未发现仓库 AGENTS.md。

移除“SSH 终端已连接，可直接在 AutoDL 工作区操作。”成功提示。工作区终端窗口上方增加上传卡片，选择本地单个文件、填写已有远端绝对目录，点击上传。默认目录 /root/autodl-tmp，可自行修改；显示所连接主机、文件名、大小、发送进度、取消入口及最终远端路径。发送进度 100% 仍显示等待远端确认，只有服务端 SFTP 写入完成才提示上传成功。未连接 SSH 时禁止上传。

新增 POST terminals/:id/upload，沿用项目归属和 x-terminal-token 校验，使用来源 Shell 的现有 SSH Client 开启 SFTP 通道，不另建 SSH 登录。浏览器以二进制请求发送文件，服务端流式传输到远端，不使用 JSON/base64，不将文件落盘至本机数据库或任务目录。单文件上限 200 MiB，前后端校验，服务端流式计数再次限制。文件名禁止路径分隔符、空字符及点目录；远端目录要求绝对路径并通过 SFTP realpath 解析，不拼接 Shell 命令。

以 wx 排他模式创建文件，拒绝覆盖已有同名文件，不自动创建远端目录。上传失败或取消时尝试删除本次创建的未完成文件，不删除原有文件。远端断线导致清理失败时可能残留部分文件，界面提示检查远端后再重试。关闭最后一个 Shell 或退出实验页面仍释放连接，进行中的上传可能中断，应在上传完成后关闭终端。首版不支持文件夹、断点续传或批量上传。

开发自验仅源码及类型声明阅读、Git 状态与变更记录；依本轮规则，没有执行 lint、类型检查、测试、构建、浏览器验证或真实 SSH 上传，尚未测试，用户验收未执行。待集中验证：普通/空文件上传、中文文件名、200 MiB 边界、目录权限及磁盘不足、同名拒绝且原文件完整、断线及取消清理、复用连接与项目 token 隔离、进度及最终确认。需要用户重启 TRASH 加载新增后端接口；本轮未自动重启或关闭平台。
