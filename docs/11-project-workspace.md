# 项目工作台与可隐藏导航

## 目标与范围

基于 ct_dev_test 的 3df46b1，将原项目列表首页与项目详情长页面改为统一工作台。每个项目的数据仍按原方式保存，没有数据库迁移，不改变原有业务端口或 Agent 配置。

左侧固定为 260px 项目导航：品牌、新建、更多操作中的知识包恢复、项目搜索、项目名称列表与主题切换。搜索匹配名称和研究问题；当前项目高亮，长名称省略并提供完整提示，项目列表独立滚动。

右侧以项目名称与研究问题为标题，使用概览、文献、卡片、Wiki、实验结果、任务六个独立页面。项目头部“⋯”提供导出和删除，删除沿用二次确认、任务保护及文件清理提示，不要求输入项目全名。

## 隐藏与窄屏

桌面端可以完全隐藏导航，内容区占用释放后的宽度；页面顶部始终提供展开/隐藏按钮，浏览器保存桌面偏好。侧栏显隐不卸载当前功能页。

宽度小于 900px 时使用默认关闭的抽屉，不覆盖桌面偏好。菜单可展开，选择项目、点击遮罩或 Escape 关闭；焦点返回顶部菜单按钮。抽屉开启时约束 Tab 焦点，减少动态效果偏好会关闭布局过渡。

## 路由与恢复

路由为 /projects/:projectId/overview、literature、cards、wiki、results、tasks。

- 根路径恢复最后访问的有效项目与页面；无记录时选择第一个项目，无项目时显示欢迎引导。
- 旧 /projects/:projectId 路径恢复该项目最后页面，默认 overview。
- 切换项目恢复其最后页面，浏览器前进、后退及深链接均由 History 管理。
- 新建或知识包恢复成功后进入项目概览。
- 删除当前项目后进入最近访问的剩余项目，没有访问记录时采用当前列表顺序；没有剩余项目时回欢迎页。
- 不存在的项目显示说明，同时保留项目导航。
- localStorage 仅保存导航、主题与最后访问偏好，读写失败使用默认行为，不影响数据库内容。

页面查询参数 action=new 打开知识对象编辑器，action=import 聚焦文献上传；focus 指向对象编辑器、来源详情或任务日志；status=pending 筛选待审对象。

页面切换前对已修改的卡片、Wiki、结果、文献元数据及新项目草稿提示放弃确认；浏览器刷新或关闭使用 beforeunload 提示。浏览器可能根据用户交互策略限制原生离开提示，需集中验收。确认切换后页面状态按路由重新创建；异步结果不写入另一个项目的组件。

## 概览接口

GET /api/v1/projects/:projectId/overview，返回 counts、pending、activities，协议为 ProjectOverview。

统计为文献总数、有已采纳版本的卡片数、Wiki 对象数、实验结果对象数；不以版本数作为对象数，不把参考论文中的数值计入自有实验。

待处理项为没有卡片的文献、最新版本待审卡片、最新版本待审 Wiki、依赖更新的 Wiki、失败或中断的任务。活动来源为文献导入、版本创建、审阅和任务状态，按时间排序显示最近 10 条，可跳转对应页面。概览只在进入或手动刷新时加载，不持续轮询；任务页继续原有任务状态轮询。

旧文献导入、公开检索、全文检索、来源管理抽取到独立文献组件；卡片/Wiki/结果/任务由外层路由控制，移除原组件内重复导航。原有业务 API 继续使用。
