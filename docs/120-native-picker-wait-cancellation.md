# 修复原生文件选择等待锁死

用户截图显示等待原生选择框时，关闭、取消和手动路径均被禁用。修复为：等待期间可关闭弹层、Escape、点击停止等待或直接填写路径并使用。每次请求绑定 AbortController，手动提交替换等待请求，组件卸载时取消；旧请求的完成/报错不覆盖新请求状态。前后端超时缩短为两分钟，超时提示改用路径。

HTTP 响应连接关闭时中止对应原生选择 execFile，释放全局选择锁；固定 PowerShell 脚本增加置顶 owner 窗体并以其作为 OpenFileDialog owner，降低文件框藏到后台的概率。用户具体宿主 Windows/WSL 的窗口显示原因尚未实测，不能保证所有桌面会话能显示；手动路径始终可用，不因原生等待被禁用。仅终止本请求启动的子进程，不关闭其他 PowerShell 或平台。WSL 互操作实际是否会连带终止 Windows GUI 需用户验收。
