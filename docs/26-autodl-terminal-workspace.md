## 操作与界面

实验内部在 AutoDL 信息右侧新增 AutoDL 工作区。原“连接与环境诊断”拆成“连接”和“环境诊断”两个按钮。

连接仅复用已保存会话认证、核对 SSH 主机指纹并申请带 PTY 的交互 Shell，不执行 Python、目录创建、磁盘/GPU 检查或实验命令。成功后自动切入工作区显示终端。已有相同主机会话时按钮为“打开终端”，不重复建立连接；切换其他主机前需要主动断开当前终端。

环境诊断继续独立执行原 Python 环境读取，不因为终端成功而自动运行；诊断失败不阻止已经打开的终端。主机未信任、密码失效等原因继续在界面显示，不自动接受指纹变化。

终端采用 xterm.js 和 FitAddon，直接接收 SSH Shell 输出并发送键盘输入，支持 ANSI 彩色、方向键、Ctrl+C、粘贴及窗口尺寸调整。它是实际远端交互终端，不是单条命令模拟框。没有额外发送 cd 或初始化命令，初始目录、环境和提示符遵循远端 Shell 的登录行为。

切换实验内页签保持终端组件与会话。退出实验页面、刷新或离开项目时释放页面持有的会话；断开连接主动关闭 Shell，不承诺前台命令继续执行。长时间任务应使用 tmux 或实验 Runner。终端与 Runner 独立，手工命令不自动生成实验计划、指标记录或结果。

## 通道与边界

使用 ssh2 Client.shell 和 xterm-256color PTY。输出通过带随机会话 token 请求头的 SSE 流传输，输入及尺寸通过同项目 POST 接口发送；不增加 WebSocket 服务或新端口。输入按顺序排队，输入过载时提示；输出按原始字节编码后交给 xterm，保留中文及控制序列。

新增接口：POST ssh-profiles/:id/connect（confirm=true）；GET terminals/:id/events、POST terminals/:id/input、POST terminals/:id/resize、DELETE terminals/:id。终端接口校验项目归属和 x-terminal-token。token 只保存在运行期内存及页面组件，不放查询字符串或本地存储。

最多同时 20 个服务会话、每项目 3 个；前端本页维护一个终端。SSH 已连接但 PTY 申请超过 15 秒时失败并清理。输出保留最近约 1 MiB 原始字节，超过范围显示截断提示，不落盘、不写任务日志；屏幕滚动缓冲 5000 行。慢速输出订阅会断开，可点“恢复终端显示”重新显示缓存。首次未附着页面 30 秒、附着后无订阅 60 秒的会话会清理，重连不承诺恢复已被清理的 Shell。

终端输入输出是远端的真实交互数据，不应假定平台会脱敏远端自己回显的秘密。服务不主动记录这些内容。当前仍为既有受信任本地部署模式。

存在活动终端或正在连接时阻止删除本地项目。对应主机终端活动时阻止修改连接配置、改名、删除配置或重新信任指纹；同连接仅补充会话密码仍可操作。服务停止流程先关闭终端与 SSE，避免持久输出连接阻止 HTTP 服务正常关闭。没有在本轮实际停止用户服务。
