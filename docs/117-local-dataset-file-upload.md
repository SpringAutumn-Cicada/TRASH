# 数据集改为本机文件直传

“上传数据集”原浏览器文件上传改为“选择本机文件”，通过项目 local-files 只读目录接口浏览后端所在电脑的普通文件。选择器支持路径、上级目录、文件名筛选与嵌套弹窗焦点；WSL 后端可浏览 /mnt/c 等已挂载路径。文件不在后端电脑时须先放到后端可访问的目录。浏览器仅提交 profile_id/name/path/extract/request_id/confirm 的小 JSON，不发送文件内容；原 datasets/upload 接口按新 JSON 协议接收，旧的浏览器二进制请求不再支持。

服务端解析绝对本机路径为真实路径，限制非空普通文件、5 GiB 和文件名安全。分块读取并计算 SHA-256，不生成上传临时副本，随后由 SFTP 读取原文件传送 AutoDL；ZIP 继续本地逐项校验与成员哈希，再远端解压。全流程是读取/校验后再传送，并非边算哈希边传网络；省掉浏览器传输和本机临时写入，仍有校验与 SFTP 各自读取开销。前后检查大小/mtime/inode，变化则停止并按原规则清理拥有的远端目录；原文件从不修改或删除。检查不能代替文件系统快照，上传期间用户应保持源文件不变。

保留 5 GiB、ZIP 解压 5 GiB/100000 条目、进度、终止、空间/权限与既有目录拒绝覆盖规则。状态显示读取校验本机文件→传输AutoDL→解压→保存；尚未取得后端进度时使用不定进度，不把 JSON 发送比例当成数据上传比例。源文件在本机时取消无临时文件清理，远端拥有目录按原流程处理。双重 busy 检查覆盖路径校验 await 后的并发请求。

分支 ct_dev_test；开始工作树干净、依赖存在，已阅读相关提交、数据集上传与本机浏览能力，未发现仓库 AGENTS.md。开发自验仅静态审阅接口、流式读取和清理边界，未执行 lint、类型检查、测试、构建、浏览器、本机文件实际读取上传或 SSH。实际用户验收待进行：本机选择、WSL路径、大文件进度、ZIP、超限/空文件、源变化、取消、无权限和已有远端目录。需要重启后端（重新 pnpm dev）并刷新页面；本次未主动重启、推送、合并或修改全局配置。
