# 本地仓库目录选择

分支：ct_dev_test；基线：bc61a2b。

在“实验 → 代码”的本地 Git 仓库根目录旁增加“浏览目录”。弹窗支持单击进入子目录、上一级、主目录、输入绝对路径跳转和选择当前目录；新建文件夹成功后直接进入，选择后回填路径。取消不改变原路径，选择不自动绑定仓库。

目录属于运行 TRASH 服务的电脑，不是浏览器设备或 SSH 实例。首次从已填写路径开始，路径为空时从服务用户主目录开始；无效路径可通过主目录按钮恢复。子目录列表不展开符号链接，不显示 .git。路径可手动输入，服务端按操作系统权限访问。

新增项目级 GET/POST repository/directories：GET 返回规范化路径、父目录及子目录，POST 只在已有父目录下创建单层文件夹。不覆盖同名文件，不递归创建，不初始化 Git，不写入仓库绑定或提交代码；名称拒绝路径分隔符、控制字符、.、.. 和 .git。新目录若需要绑定，须先由用户在本地初始化为 Git 仓库。

弹窗包含键盘焦点约束、Escape 关闭、关闭后焦点恢复、加载与错误提示；忙碌时禁止重复目录操作。

开始前核对 Git 状态、近期提交、相关文件历史及依赖目录，工作树干净；仓库内未发现 AGENTS.md。修改范围为目录操作接口、实验页面入口、目录选择组件与样式及本记录。
