# 弹窗上方统一错误提示

分支 ct_dev_test，基于 2526dc1。开始时工作树干净，已读取统一 ModalLayer、SSH 连接错误归属及相关文件历史，依赖目录存在。

新增 ErrorNotice，统一替换工作台现有静态错误提示及诊断/文件上传动态错误。没有弹窗时仍内联显示；存在弹窗时通过 portal 放到 modal-root 内独立错误层，定位于最上层弹窗上方约 14px，宽度跟随弹窗，z-index 高于嵌套目录选择层。多条提示垂直排列，限高滚动，不被项目顶栏或背景 inert 遮挡。

ModalLayer 发布打开数量变化，统一管理提示定位；使用 ResizeObserver、MutationObserver 及窗口 resize/scroll 响应弹窗尺寸和嵌套层变化。存在错误时为弹窗预留顶部空间，避免长弹窗顶住屏幕遮住提示。隐藏浏览器或后台保活终端产生的内联错误不从 hidden 区域提升显示；上传表单与页面同一错误避免重复渲染。

父页面 connectTerminal 捕获的连接失败通过 ErrorNotice 自动提升，因此即使错误不由上传弹窗自己产生，也可在上传弹窗上方看到。关闭全部弹窗后回到原页面位置，不改变请求、SSH 或上传逻辑。

实际只读检查与前端修改，没有运行 lint、类型检查、测试、构建或浏览器验证；尚未测试，用户验收未执行。待集中验证连接失败、嵌套目录、多条错误、窗口缩放、长弹窗、hidden 保活视图及提示无重叠。未合并、未推送、不修改全局配置。

生效方式：当前单端口开发启动会托管构建后的前端，需要停止旧进程后运行 pnpm dev 重新构建启动并刷新浏览器；本轮未主动重启。
