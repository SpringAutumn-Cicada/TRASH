# 远端目录默认路径与错误分类

分支 ct_dev_test，基线 9169521。开始时工作树干净，核对近期提交、目录浏览历史、依赖目录，未发现仓库 AGENTS.md。

源码发现上传默认父目录原设为 /root/autodl-tmp/trash-reproductions，但浏览器不会创建该目录，首次使用实例时可能尚不存在。SSH 连接成功不代表此路径已存在。此前服务端把全部 SFTP realpath/readdir 失败合并为同一提示，无法确定现场究竟是路径不存在或权限问题。

默认上传父目录改为 /root/autodl-tmp。SFTP 根据状态区分不存在、无权限和连接丢失；保留其他读取失败的明确错误。目录弹窗首次打开时，仅当返回“不存在”才逐级回退到存在的父目录，并提示选择上传位置；权限或连接问题不作静默回退。用户手动输入路径时直接显示对应错误。读取不创建目录或修改权限，保留根目录入口。上传仍在所选父目录下创建独立快照子目录。

本轮未连接 AutoDL，不能宣称已经确认用户实例的路径或权限。实际开发自验仅 Git 状态、历史、源码阅读；未运行 lint、类型检查、测试、构建或浏览器验证，尚未测试，用户验收未执行。待验收：初始路径不存在时回退、根目录失败、无权限、连接中断、手动路径及选择上传。

需重启后端加载 SFTP 错误分类；未自动重启或关闭平台，未修改全局配置、未合并或推送。
