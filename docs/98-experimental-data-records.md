# 实验数据记录模块

“数据集”右侧新增“实验数据”，其后保留对比实验、消融实验。复用本项目 experiment-result 版本化记录，不额外复制结果：现有远端实验采集、手动新建、JSON 导入、编辑、审阅、历史及导出能力均可在本模块使用，与原“实验结果”页面共享记录。第一次进入才挂载，内部切页保留编辑状态。附件、配置和环境可使用现有高级 JSON 字段。

上方展示最新记录与最佳记录。比较范围按方法、数据集及其版本、任务、划分、评价协议分组；指标按名称、单位、条件区分，支持越大越好或越小越好。配置和随机种子允许不同，显示的是单次结果排名，不宣称均值或统计显著性。默认包含所有未拒绝记录，允许限制为已采纳记录，卡片显示实际审阅状态。条件缺失时明确提示不能认定条件一致。缺失、非有限值或同条件重复指标不参与最佳排名。

最新按 run_at 排序，无运行时间时按记录时间；同分最佳优先较新运行。摘要读取当前项目全部记录的当前版本，记录历史仍由编辑器查看。下方表格保留独立查询与分页，不把表格当前页误当全项目最佳。摘要支持刷新、当前页签可见时约十秒轮询，表格保存/导入/审阅/刷新后通知摘要重读。查看摘要卡片打开原记录编辑器。
