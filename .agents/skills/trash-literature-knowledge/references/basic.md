# 基本信息卡片

论文基本信息任务只生成 idcard.md，使用任务指定路径 literature/cards/idcard-<source_id>.md，frontmatter：knowledge_version: 2、id与文件名相同、kind: literature-card、source_id真实来源、kind: literature-card。

正文只用下列固定的顶层单行字段（中文冒号，每项一次、不得空白），正文仍是Markdown，不返回JSON。未知值写“未核实”，没有地址写“未找到”或“无”。字段后可附证据链接，不另起同名字段。

```markdown
# 论文基本信息

- 标题：原文正式标题
- 作者：按原文顺序，使用中文顿号分隔（如Alice Smith、Bob Jones）
- 期刊／会议：未核实
- 发表年月：2025-03
- DOI／论文链接：https://doi.org/...
- 源码状态：未核实
- 官方源码地址：未核实
- 第三方实现地址：未找到
- 证据与备注：标题与作者见PDF第1页；日期依据：正式发表；月份见版权页；源码链接未实际访问
```

发表年月只允许YYYY-MM、YYYY、未核实。优先正式发表，其次在线发表；证据与备注必须写“日期依据：正式发表”或“日期依据：在线发表”，否则平台不回填日期。不能拿收稿/录用日期充当发表日期。只有预印本日期时发表年月填未核实，备注预印本年月，不冒充正式发表。只确认年份就写年份，不猜月份。

源码状态只允许官方公开、声明未公开、未找到、未核实。论文写了明确官方地址可记官方公开，但备注“论文声明公开，链接未核验”；没有官方地址不能记官方公开。未找到不等于没有源码。官方与第三方分开，地址必须是材料中的http/https链接，不猜仓库、不开网络自动搜索，不宣称访问过未访问的地址。多个地址同一行空格分隔。无源码不妨碍其余卡片发布。

标题原文不详填未核实，平台保留原值。平台尝试回填标题、作者与发表年月，期刊/DOI/源码保留本卡，不静默改其他字段。人工保护或并发修改时保留原值，生成建议由用户确认。卡片编辑并不等于确认使用建议。
