# TRASH 项目技能

本目录随项目分发。所有 TRASH 自研技能的目录名和 SKILL.md frontmatter name 必须以 trash_ 开头。不安装到用户全局技能目录，不修改全局 Codex 配置。

trash_analyze_code_environment 用于文献复现的只读源代码分析（部署环境、数据集需求与实验运行方案）。平台使用独立任务目录、固定输入与结构化报告校验；调用技能本身不授权安装、联网、部署或执行论文代码。

Skill 2.3.0 的源代码报告增加逐数据集的自动执行协议：必需路径、绑定适配、阶段参数、评价条件、指标采集规则和有依据的 checkpoint 恢复。识别不完整时标明阻塞项，不要求用户手填 JSON，也不代表已经执行验证。

Skill 2.4.0 明确区分从头训练、已有权重评估和完整检查点继续训练，输出模型输入/产物与 CPU、多 GPU 支持依据；实际主机资源由平台读取。

Skill 2.5.0 将处理方式（分批/实体）与权重模式（重新训练/已有权重）分开分类；未知处理方式不可自动运行。
