# 仅摘要文献分析

读取 input.json 中指定论文的基本信息和摘要，仅使用本次提供的摘要。直接将 Markdown 写入提示词指定的 output/ 路径。

每份输出必须包含一级标题、`材料范围：仅摘要` 和 source_id。正文以简洁中文暂分为基本信息、摘要解读、研究线索、待全文核验四节；分析字段与深度可以后续细化。

基本信息沿用提供的作者、日期、DOI和链接；不猜月份、源码状态或源码地址。摘要未提到的内容写“摘要未提供”。描述贡献、实验与效果时使用“作者在摘要中报告/声称”，不当作已核验事实。不猜具体架构、数据划分、指标、消融及局限。区分摘要原文、你的推断和待验证问题。

研究线索只作为候选方向，不能写成已被全文证据支持的正式知识主题。不读取全文库，不联网寻找全文，不执行代码或实验。引用以“摘要”定位，禁止伪造PDF页码。原始摘要只读，避免重复粘贴长段原文；正常结果约600–1200字，不嵌入base64，单文件不超过1MiB。完成后回读目标文件，最终回复给出文件路径。
